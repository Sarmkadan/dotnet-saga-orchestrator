# Security Policy

## Reporting a Vulnerability

We take the security of dotnet-saga-orchestrator seriously. If you discover a security vulnerability within this project, please do not report it through public GitHub issues.

Instead, please report it by:
1. Using GitHub's built-in private vulnerability reporting (Private Advisory) feature on this repository.
2. Alternatively, contacting us directly at **rutova2@gmail.com**.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to provide a timeline for a fix or further updates.

## Supported Versions

Currently, the following versions of dotnet-saga-orchestrator are being supported with security updates:

| Version | Supported          |
|---------|--------------------|
| 2.0.x   | :white_check_mark: |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |
