# Contributing to dotnet-saga-orchestrator

Contributions are welcome!

## Development
1. **Clone**: `git clone https://github.com/sarmkadan/dotnet-saga-orchestrator.git`
2. **Build**: `dotnet build`
3. **Test**: `dotnet test`

## Guidelines
- Follow the existing `.editorconfig` style.
- Include XML documentation for new public APIs.
- Write unit tests for all features and bug fixes.
- Ensure all tests pass.

## Submitting Changes
- Create a feature branch.
- Submit a Pull Request against `main`.
- Describe changes clearly and reference related issues.
